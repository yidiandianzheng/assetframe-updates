# 图库分类 · 标签数据与状态规则

把素材库里的图片按「品牌 / 茶类 / 产品线 / 机位 / 图类型 / 用途 / 比例 / 验收 / 整理状态」归类，产出图库界面可以直接读取的分类结果。

**边界**：只读素材库（`mode=ro`），不写数据库、不改原素材、不调用任何模型。结果写在本目录下，是否回写素材标签需要单独授权。

## 目录

```
图库分类/
├── 产品名称映射表.json      # 品牌 / 茶类 / 产品线 / 机位 / 图类型 / 用途 的取值与别名
├── 分类规则.md              # 判定优先级、冲突处理、状态规则
├── classify.py              # 分类引擎（只读库 → 输出结果）
├── build_preview.py         # 把结果渲染成单文件核验页
├── 预览.html                # 核验页：完整徽标 + 可点选筛选（双击打开）
└── 输出/
    ├── 分类结果.json        # 全量 2565 张图片的分类结果（界面消费）
    ├── 分类结果.csv         # 同上，Excel 可读
    ├── 筛选核验.json        # 各维度计数与一致性校验
    └── 覆盖率报告.md        # 识别率、冲突、未识别样本
```

## 复跑

```sh
cd "/Volumes/SSD-1TB/06-工具与开发/资产管理（图文）App"
python3 图库分类/classify.py          # 重新分类（默认读香万家木兰库）
python3 图库分类/build_preview.py     # 重新生成核验页
```

换库：`python3 图库分类/classify.py --db "/path/to/x.assetframelibrary/global-material-library.sqlite"`。

## 字段契约（供图库界面读取）

每条记录：

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `scope` | 产品图 / 人物图 / 分镜图 / 场景图 / 品牌资产 / 文档页面 / 其他素材 | 主视图只取「产品图」 |
| `brand` | 香万家 / 中茶 / 茶盈航 / 岁三窖 / 千茶素材 / 未识别 / 不适用 | 卡片第一徽标 |
| `tea_type` | 乌龙茶 / 红茶 / 白茶 / 黑茶 / 黄茶 / 绿茶 / 未分类 / 不适用 | 卡片第二徽标 |
| `product_line` | 映射表里的产品线名 / 未归类 / 不适用 | 对应截图里的「商品」维度 |
| `shot` | 正面 / 斜侧面 / 侧面 / 背面 / 顶部俯视 / 底部 / 近景特写 / 全景 / 未标注 | 机位 |
| `asset_kind` | 包装设计稿 / 平面设计稿 / 透明素材 / 对比图 / 字体字样 / 视频抽帧 / PPT页面 / AI生成图 / 实拍照片 / 图片素材 | 图类型（本脚本不产 `asset_type` 资产类型，那一维只在 App 侧规则里） |
| `usage` | 设计素材 / 社媒海报 / 商品主图 / 详情页 / 短视频封面 | 用途 |
| `ratio` | 1:1 / 4:3 / 3:4 / 16:9 / 9:16 / 3:2 / 2:3 / 矢量 / 其他 / 未知 | 比例 |
| `acceptance` | 已确认 / 待确认 / 待核 | 来源验收状态 |
| `organize_status` | 可用 / 待整理 / 待补标签 / 不适用 | 见规则文档 |
| `source` | 本机引用 | 固定值 |
| `evidence` | 每个维度命中的依据（文件名 / 目录名 / 产品线） | 便于人工复核 |
| `conflicts` | 冲突说明数组 | 需要人工裁决的条目 |
