## 导出库

1. 在图片画册中多选要使用的素材，点击“加入导出库”。
2. 在导出库修改“导出名称”，查看最终文件名和分类目录预览。
3. 交付健康检查会区分阻塞与提醒：缺图、未命名、未分类阻止导出；重复内容、非正式候选和低分辨率提示复核，并可跳回对应资产。
4. 正式导出时，在当前原图和历史版本中自动选择像素总量最高的可用文件，原图直接复制、不压缩，并生成 `资产清单.csv`。

`1K / 2K / 4K` 按图片最长边识别：1K 从 1024 像素起，2K 从 2048 像素起，4K 从 3840 像素起。导出清单会记录实际输出原图路径、像素尺寸和清晰度标签。

导出结构：

```text
项目名_资产导出_yyyyMMdd_HHmm/
├── 人物资产/
├── 道具资产/
├── 场景资产/
├── 通用资产/
└── 资产清单.csv
```

默认文件名为 `类型_导出名称_等级_版本.扩展名`，非法字符自动清理，重名时追加 `_02`、`_03`。通用分类优先进入“通用资产”；人物/生物进入人物，场景/场地进入场景，其余视觉资产进入道具。

## 性能验收

`SelfTests/PerformanceSelfTest.swift` 会构建 5,000 条资产、执行旧库迁移、缓存后页面切换、重复搜索、单条修改、干净项目保存检查和 SQLite 重开。当前本机结果：

- 5,000 条旧库后台迁移：约 1.30s，期间界面保持可点击。
- 缓存后视图切换平均：约 2.22ms。
- 20 次相同搜索（含首次筛选）：约 34.1ms。
- 单条修改与派生缓存更新：约 15.6ms。
- 无修改项目保存检查：约 0.002ms，不执行整库写入。
- SQLite 重开 5,000 条：约 252.1ms。

高清预览使用 `PreviewImagePipeline` 在后台通过 ImageIO 下采样：首次打开按屏幕像素快速显示，只有缩放到 `1:1` 才请求完整原图。预览和原图均按来源版本、目标像素尺寸和显示模式缓存；切换图片会取消过期读取。可用以下命令运行有效 4K PNG/JPEG/HEIC 基准：

```bash
zsh run-self-tests.sh
```

输出中的 `cold`、`warm_p95` 和 `full` 分别表示首次窗口预览、缓存命中和 1:1 原图解码耗时；该结果只代表当前 Mac、本机系统和本地存储，不作为跨机器承诺。
合成 HEIC 若没有内嵌预览会显示 `WARN`；最终 HEIC 验收应使用真实相机/生成器素材，以验证内嵌预览路径。

### 文件夹拖入（V260905.2）

从访达把一个或多个文件夹拖到主窗口，松开后自动进入素材总库，递归导入子文件夹内的文件。图片、音频、视频沿用总库的元数据识别、去重和逐项结果；隐藏文件及软件包内部不展开，原文件保留原位。单独文件继续按当前工作区导入。已有导入任务时，请等待完成或取消后重新拖入。

V260907.4 起，目录扫描和素材读取同时进行：首批素材建立索引后立即出现在素材总库，后续文件继续在后台分批提交。进度卡显示已可浏览数量、扫描状态和预计剩余时间；再次导入路径、大小和修改时间均未变化的来源时，不会重新读取整份文件计算 SHA256。
